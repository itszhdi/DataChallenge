## Запуск фронтенда с бэкендом

1. Настройте `backend/.env` по `backend/.env.example`: укажите `DATASET_API_URL` и параметры LLM.
2. Запустите API из `backend` командами `make install` и `make run` (API будет доступен на `http://localhost:8000/api`).
3. Откройте `frontend/index.html` в браузере. На вкладке «Диалоги» в блоке «Источник данных» укажите URL API и dataset/group ID, затем нажмите «Загрузить из бэкенда».
4. Нажмите «Оценить» для одного диалога или «Оценить все». Оценка выполняется API бэкенда и сохраняется в его SQLite базе.

Голосовые звонки по умолчанию исключены из отправки в LLM (`EXCLUDE_CHANNELS` в `.env` бэкенда). При открытии фронтенда с другого домена/порта добавьте его в `CORS_ORIGINS`.

Фронтенд сохраняет для дальнейшей выгрузки JSON в браузере, а бэкенд хранит оценки в SQLite. Для оценки с бэкенда сначала импортируется набор, заданный в `DATASET_API_URL`.
