## Запуск

**Бэкенд** (Python и `uv`):

1. Скопируйте `backend/.env.example` в `backend/.env`, укажите `DATASET_API_URL` и параметры LLM.
2. В папке `backend` выполните `make install` и `make run`. API будет доступен на `http://localhost:8000/api`.

**Фронтенд** (Node.js 20+):

1. В папке `frontend` выполните `npm install`.
2. Если API работает на другом адресе, скопируйте `frontend/.env.example` в `frontend/.env` и измените `VITE_API_URL`.
3. Выполните `npm run dev` и откройте адрес из терминала, обычно `http://localhost:5173`.

Для сборки используйте `npm run build`, результат появится в `frontend/dist`.

## Как пользоваться

1. На странице «Диалоги» нажмите «Импорт» и укажите `group_id`, ссылку или файл JSON.
2. Нажмите «Оценить неоценённые» или кнопку «Оценить» в строке диалога.
3. Откройте диалог: ссылки `#N` в обосновании ведут к нужной реплике, а в звонке ещё и перематывают запись.
4. Кнопкой «Оспорить» подайте апелляцию. Решение проверяющего принимается в том же критерии, итог пересчитывается автоматически.
5. На странице «Общий отчёт» клик по карточке или столбцу графика фильтрует таблицу проблемных диалогов.
6. В «Настройках» меняются критерии и веса, порядок очереди, потоки, задержка, автооценка после импорта и `group_id`. Для локальной модели Qwen 3.5 9B используйте блок LM Studio из `backend/.env.example`.

Голосовые звонки по умолчанию не отправляются в LLM (`EXCLUDE_CHANNELS` в `backend/.env`). Для запуска фронтенда с другого домена добавьте его в `CORS_ORIGINS`.

Все оценки и апелляции хранятся в SQLite на бэкенде. В браузере остаются только язык, тема, выбранный набор и параметры экспорта.
